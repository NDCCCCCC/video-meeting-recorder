<decisions_made>

- **Decision: Do not invalidate slide cache after reordering**
  - Rationale: After reordering JPEG images in the cache directory, the cache IS the source of truth for slide order. Invalidating causes re-extraction from the PPTX file which still has the original order, defeating the purpose of reordering.

- **Decision: Read request body before JSON binding for error logging**
  - Rationale: `ShouldBindJSON` consumes the request body, so to log the actual request payload for debugging 400 errors, we must read the body first using `GetRawData()`.
</decisions_made>
