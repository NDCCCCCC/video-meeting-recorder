# Quick Task 260730-eis: 清理构建阻塞 + line-ending 修复

## 目标

清理三处构建/测试阻塞：

1. **`app.go` line-ending 核查**：`./cmd/server/app.go` 已为 LF（实测 0 个 CR 字符、1495 行 LF）。本任务做一次 defensive 校验，确保无误后保持现状；若未来重新出现 CRLF，CI 应捕获。
2. **`frontend/dist` 占位**：`frontend/dist/` 在根 `.gitignore` 中被忽略（line 6-8），目录内有 `assets/` 与 `index.html`，但因 gitignore 未被纳入版本控制。新增 `frontend/dist/.gitkeep` 并通过 `git add -f` 强制纳入（保持占位语义，不影响实际构建产物）。
3. **`ip_restriction_test.go` ctx 透传**：`./internal/auth/ip_restriction_test.go` 在 8 处 `service.CheckIPRestriction(ctx, ...)` 中使用了未定义的 `ctx` 变量（line 112, 162, 217, 269, 317, 383, 432, 455）。`CheckIPRestriction` 签名是 `func (s *Service) CheckIPRestriction(ctx context.Context, user *models.User, clientIP string) error`（`./internal/auth/service.go:139`）。修复方式：在每个使用 `ctx` 的测试函数中加 `ctx := context.Background()`，并在 import 块补 `"context"`。`./internal/models/ip_restriction_test.go` 未涉及 `ctx`，无需改动。

## 任务清单

### Task 1: app.go line-ending 防御性核查

- **文件**：`./cmd/server/app.go`
- **动作**：
  1. 验证文件无 CR 字符（`grep -c $'\r' ./cmd/server/app.go` 应为 0）
  2. 若有 CR，运行 `dos2unix` 或 `sed -i 's/\r$//' ./cmd/server/app.go` 转换为 LF
  3. 若已为 LF，no-op
- **verify**：`od -c ./cmd/server/app.go | head -1` 显示 `\n` 结尾
- **done**：文件为纯 LF，CRLF 已清零

### Task 2: frontend/dist/.gitkeep 强制纳入

- **文件**：`./frontend/dist/.gitkeep`（新建）
- **动作**：
  1. 创建 `frontend/dist/.gitkeep`（空文件，加占位注释 `# Frontend build output directory — keep tracked for tooling compatibility. Build artifacts under assets/ and index.html are regenerated by Vite.`）
  2. 因根 `.gitignore` 第 6 行 `dist/` 忽略该目录，使用 `git add -f frontend/dist/.gitkeep` 强制纳入
- **verify**：`git ls-files frontend/dist/.gitkeep` 返回路径
- **done**：`.gitkeep` 已 tracked，目录在 `git ls-files` 中可见

### Task 3: ip_restriction_test.go 透传 ctx

- **文件**：`./internal/auth/ip_restriction_test.go`
- **动作**：
  1. 在 `import` 块添加 `"context"`
  2. 在以下 8 个测试函数开头（紧跟 `db := setupTestDB(t)` 之后或测试体开头）加 `ctx := context.Background()`：
     - `TestCheckIPRestriction_UserOnly` (line 75)
     - `TestCheckIPRestriction_RoleOnly` (line 125)
     - `TestCheckIPRestriction_UserAndRole_OR` (line 175)
     - `TestCheckIPRestriction_NoRestrictions` (line 230)
     - `TestCheckIPRestriction_IPNotInList` (line 281)
     - `TestCheckIPRestriction_MultiRoleMerge` (line 330)
     - `TestCheckIPRestriction_InvalidClientIP` (line 396)
     - `TestCheckIPRestriction_AuditLogOnFailure` (line 445)
  3. 保持 `service.CheckIPRestriction(ctx, ...)` 调用不变
- **verify**：`cd backend && go test ./internal/auth/... -run TestCheckIPRestriction` 通过编译并运行成功
- **done**：所有 8 个测试通过 `go vet` 与 `go test` 编译，运行时无 undefined `ctx` 报错
