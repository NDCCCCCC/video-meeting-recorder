## Interaction Patterns

### Timeline Marker Interactions

| Action | Trigger | Response |
|--------|---------|----------|
| Add marker | Click on timeline | Create marker at clicked timestamp, add visual indicator |
| Add marker (precise) | Enter timestamp in input field | Validate range (0 to video duration), add marker |
| Remove marker | Click existing marker | Remove marker from timeline and list |
| Reposition marker | Drag marker along timeline | Update timestamp in real-time (implementation: custom drag handler) |
| View marker details | Hover marker | Tooltip showing timestamp in MM:SS format |

**Validation:**
- Timestamps must be within video duration range
- Minimum 2 seconds between markers (prevent FFmpeg errors)
- Maximum 20 markers per video (prevent performance issues)

**Source:** CONTEXT.md decisions D-01 through D-04

### Split Execution Flow

```
User clicks "确认分割"
  ↓
Validate markers (min 2 markers, max 20, sorted, no duplicates)
  ↓
Show confirmation modal: "确认将视频分割为 {N} 个段落？"
  ↓ [User confirms]
Disable "确认分割" button, show loading spinner
  ↓
API call: POST /api/v1/videos/{id}/split
  ↓
Poll for progress (WebSocket or 2s interval)
  ↓
On complete: Success notification + redirect to file list
  ↓ [On error]
Error notification with message, re-enable button
```

**Error states:**
- FFmpeg process failed: Show error message, offer "重试" button
- Insufficient disk space: Show specific error, offer "清理空间" guidance
- Video file corrupted: Show error, suggest "重新录制" or "检查源文件"

**Source:** RESEARCH.md §Pitfalls, CONTEXT.md §Split Precision vs Speed

## Accessibility Requirements

### Keyboard Navigation
- Timeline markers: Tab through markers, Enter/Space to add/remove
- Video player: Standard media keys (Space=play/pause, arrows=seek)
- Modal: Escape to close, Tab to cycle through controls

### Screen Reader Support
- Marker positions: Announce "Marker at {MM:SS}" on focus
- Timeline interaction: "Click to add marker at {current time}"
- Segment list: "Segment {N}, from {start} to {end}, duration {length}"

### Visual Accessibility
- Timeline markers: Minimum 44px height for touch targets
- Color contrast: WCAG AA compliant (Ant Design default)
- Focus indicators: Visible focus ring on all interactive elements

**Source:** CONTEXT.md D-03 (second-level precision), Ant Design accessibility features

## Performance Considerations

### Timeline Rendering
- Markers rendered as Ant Design Slider marks (optimized virtual rendering)
- Maximum 20 markers to prevent DOM bloat
- Debounce marker drag events (100ms) to reduce re-renders

### Video Player
- Lazy load video element on modal open
- Preload metadata only (not full video) to reduce bandwidth
- Unload video source on modal close

### Split Progress Polling
- WebSocket preferred for real-time updates (if infrastructure exists)
- Fallback: 2-second polling interval with exponential backoff on errors
- Cancel polling on component unmount

**Source:** RESEARCH.md §Pitfalls 4 (Frontend State Desync), §Open Questions 3 (Real-time updates)
