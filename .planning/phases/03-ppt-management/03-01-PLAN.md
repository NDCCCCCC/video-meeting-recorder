    ### 4. Create extract_slides.py (scripts/extract_slides.py)

    New Python script following the exact pattern of scripts/create_pptx.py (JSON IPC, stdout output, exit codes).

    Usage: `python3 extract_slides.py <pptx_path> <output_dir>`

    Implementation:
    - Import: sys, json, os, io from pptx import Presentation, from PIL import Image
    - Create output directories: `output_dir/thumbnails/` and `output_dir/fullsize/`
    - For each slide in the presentation:
      - Iterate shapes looking for shape_type == 13 (MSO_SHAPE_TYPE.PICTURE)
      - Extract image blob from shape.image.blob
      - Open with PIL Image.open(io.BytesIO(image_bytes))
      - Convert to RGB mode
      - Save full-size as JPEG quality 90 to `fullsize/slide_{idx:03d}.jpg`
      - Resize to (200, 112) using Image.LANCZOS, save as JPEG quality 85 to `thumbnails/slide_{idx:03d}.jpg`
      - If no image found in slide, create a white 1920x1080 placeholder with "Slide {idx+1}" text
    - Output JSON to stdout: `{"success": true, "slide_count": N, "slides": [{...}]}`
    - Each slide object: `{"slide_number": N, "thumbnail_path": "thumbnails/slide_XXX.jpg", "fullsize_path": "fullsize/slide_XXX.jpg"}`
    - On error: output `{"success": false, "error": "message"}` to stdout, exit code 1
    - NO stderr output (per Phase 2 D-14 decision about JSON parsing issues)
