| Option | Description | Selected |

| Option | Description | Selected |

## 本地字幕生成方案（2026-05-12 更新讨论）

### 需求变更

用户明确要求：字幕生成使用**本地实现**，不使用云服务（如通义听悟）。

### 方案对比

| 方案 | 优势 | 劣势 | 用户选择 |
|------|------|------|----------|
| **Sherpa-ONNX + Paraformer** | 中文准确率高、官方Go绑定、完全离线、资源占用低 | 模型仅支持中英文 | ✅ 选择 |
| **Whisper.cpp Go Bindings** | 多语言支持、模型成熟 | 维护状态不确定、中文准确率略低 | ❌ |
| **云服务（通义听悟）** | 无需本地资源、准确率高 | 需要公网访问、持续成本 | ❌ 用户排除 |

### 需求分析

| 需求维度 | 用户选择 | 技术影响 |
|----------|----------|----------|
| 优先级 | 中文准确性优先 | 选择 Paraformer 模型 |
| 资源环境 | 资源受限 | 选择 Small 版本模型（~40MB） |
| 处理模式 | 离线批量处理 | 异步任务队列，非实时 |
| 触发方式 | 自动触发 | 上传 + 录制完成后自动 |

### 技术决策

| 决策项 | 选择 | 说明 |
|--------|------|------|
| ASR 引擎 | Sherpa-ONNX | 官方 Go 绑定 `github.com/k2-fsa/sherpa-onnx-go` |
| 中文模型 | Paraformer-zh-small | ~40MB，< 500MB 内存 |
| 模型存储 | `/models/sherpa` | 支持环境变量覆盖 |
| 音频预处理 | FFmpeg | MP4 → WAV 16kHz 单声道 |
| 处理速度 | ~0.5x 实时 | 1分钟音频约需2分钟 |
| 触发场景 | 上传 + 录制 | 新视频创建后自动触发 |
| 进度反馈 | 完成后通知 | 异步任务，无需实时进度 |

### 触发场景补充

用户补充：录制任务完成后生成的新视频也应自动触发字幕生成。

**最终触发场景：**
1. **上传视频**: 文件上传成功、转码完成后
2. **录制视频**: 录制任务完成、视频文件保存后
