## 字幕格式与加载

| Option | Description | Selected |
|--------|-------------|----------|
| 仅WebVTT（推荐） | WebVTT是HTML5原生支持的标准格式，无需额外解析，浏览器可直接渲染 | ✓ |
| WebVTT + SRT | 需要前端解析库（如subtitle.js），增加复杂性但用户更熟悉 | |
| WebVTT + SRT + ASS/SSA | 支持更多格式，需要强大的解析库，文件体积较大 | |

**User's choice:** "你来决定，字幕来源是当前项目使用语音识别生成，因此不需要考虑兼容性，只要能用，越简单越好。"

**Notes:** 用户要求最简单的方案，选择WebVTT格式

## 字幕来源与存储

### 字幕内容如何生成？

| Option | Description | Selected |
|--------|-------------|----------|
| 从现有转录结果提取 | 复用通义听悟转录结果（但需要确认API是否返回时间轴数据） | |
| 单独的字幕生成服务 | 独立的字幕生成功能，用户上传视频后生成WebVTT文件 | ✓ |
| 用户上传字幕文件 | 用户上传已有的字幕文件（.vtt） | |

**User's choice:** 单独的字幕生成服务

### 生成的字幕文件如何存储？

| Option | Description | Selected |
|--------|-------------|----------|
| 作为独立文件存储（.vtt） | 字幕文件存放在视频文件旁边，通过相对路径引用 | |
| 存储在数据库中 | 字幕内容存在数据库，API返回给播放器 | |
| 混合方式 | 本地视频存储为文件，云视频存储在OSS | |

**User's choice:** 存储在数据库中 → **后修改为** 字幕文件存储在视频文件同目录（命名：{视频文件名}.vtt）

**Notes:** 用户在讨论结束后要求修改存储方式，改为文件存储
