**Location:** Below video player, separate from video overlay

**Dimensions:**
- Max height: 30% of video container height

- Visible when subtitle is enabled and content is available
- Hidden when subtitle is disabled or no content

- Fade in/out: 200ms ease-in-out
- Smooth transition for position changes

## Interaction Patterns

### Subtitle Toggle

**Trigger:** Button in video player control bar (next to download button)

**States:**
1. **Off (default):** Subtitle panel hidden, button shows "CC" icon
2. **On:** Subtitle panel visible, button shows active state with blue color

**Behavior:**
- Click toggles subtitle visibility
- If no subtitle file available, button is disabled with tooltip "暂无字幕"
- State persists during video playback
- Resets to off when modal closes/reopens

### Font Size Adjustment

**Trigger:** Dropdown or segmented control in subtitle settings menu

**Options:**
- Small: 14px
- Medium: 16px (default)
- Large: 18px

**Behavior:**
- Immediate change to subtitle text size
- Affects all subtitle lines
- Selection persists during session

### Position Selection

**Trigger:** Radio buttons or segmented control in subtitle settings menu

**Options:**
- Top: Subtitle panel at top of video container
- Center: Subtitle panel vertically centered (overlaying video with semi-transparent background)
- Bottom: Subtitle panel below video (default, separate area)

**Behavior:**
- Immediate repositioning of subtitle panel
- For "center" position, subtitle overlays video with semi-transparent background
- For "top" and "bottom", subtitle remains in separate area
- Selection persists during session

### Style Customization

**Trigger:** Color pickers in subtitle settings menu

**Options:**
- Text color: Color picker with preset colors (white, black, yellow, cyan)
- Background color: Color picker with transparency slider
- Outline: Toggle switch with color picker

**Behavior:**
- Real-time preview of style changes
- Background color supports alpha channel (0.0 - 1.0)
- Outline adds text-shadow effect
- Defaults: white text, black semi-transparent background (0.8 opacity), no outline

## Subtitle Synchronization

### WebVTT Parsing

**Format:** WebVTT standard format

**Example:**
```webvtt
WEBVTT

00:00:01.000 --> 00:00:04.000
这是第一句字幕

00:00:04.500 --> 00:00:08.000
这是第二句字幕
```

**Parsing:**
- Use WebVTT API or simple parser for time-based display
- Parse timestamps to milliseconds for precise syncing
- Support multi-line subtitles

### Sync Mechanism

**Trigger:** Video `timeupdate` event (fires approximately every 250ms)

**Logic:**
1. Get current video time (`video.currentTime`)
2. Find active subtitle cue based on time range
3. Display subtitle text if active cue exists
4. Clear subtitle if no active cue

**Edge Cases:**
- Video seeking: Update subtitle immediately on seek
- Video pause: Keep current subtitle visible
- Video end: Clear subtitle or show last cue
- No subtitle file: Hide subtitle panel

## Integration Points

### API Endpoints

**GET /api/v1/files/{file_id}/subtitle**
- Returns subtitle file URL or VTT content
- Requires token authentication
- Returns 404 if subtitle file doesn't exist

**GET /api/v1/files/{file_id}/subtitle/download**
- Streams VTT file content
- Requires token authentication
- Used by frontend to fetch subtitle data
