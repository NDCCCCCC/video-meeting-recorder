3. exportAuditLogs function per D-24/D-25:
```typescript
export async function exportAuditLogs(params: AuditLogExportParams): Promise<Blob> {
  const queryParams = new URLSearchParams()
  if (params.username) queryParams.append('username', params.username)
  if (params.action) queryParams.append('action', params.action)
  if (params.module) queryParams.append('module', params.module)
  if (params.start_time) queryParams.append('start_time', params.start_time)
  if (params.end_time) queryParams.append('end_time', params.end_time)
  queryParams.append('format', params.format || 'csv')

  const query = queryParams.toString()
  const response = await fetch(`/api/v1/audit/logs/export${query ? `?${query}` : ''}`, {
    headers: {
      'Authorization': `Bearer ${localStorage.getItem('token')}`,
    },
  })

  if (!response.ok) {
    throw new Error(`Export failed: ${response.statusText}`)
  }

  return response.blob()
}
```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-02 | Tampering | CSV export generation | mitigate | Escape values starting with "=", "+", "-", "@" by prepending "'" to prevent Excel formula injection. Validate in exportCSV helper. |
| T-10-04 | Denial of Service | Large export requests | mitigate | Enforce max 10k row limit per export (req.PageSize = 10000). Add timeout to context. Return error if exceeded. |
| T-10-05 | Information Disclosure | Audit log export | mitigate | Apply data_scope filtering (existing in auditService.Query). Redact sensitive fields from OldData/NewData before export (existing audit log model excludes passwords). |
