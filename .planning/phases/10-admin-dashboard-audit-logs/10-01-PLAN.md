```go
    Transcripts  int64   `json:"transcripts"`
    Ppts         int64   `json:"ppts"`
}

type SystemStats struct {
    DiskUsagePercent float64 `json:"disk_usage_percent"`
    MemoryUsagePercent float64 `json:"memory_usage_percent"`
    ErrorCount       int64   `json:"error_count"`
    ApiCalls         int64   `json:"api_calls"`
}
```

3. GetDashboardStats method implementing database aggregations:
```go
func (s *DashboardService) GetDashboardStats(ctx context.Context) (*DashboardStatsResponse, error)
```

Implementation details per RESEARCH.md Pattern 1:
- Use GORM aggregation queries with Model().Select().Scan()
- Task stats: COUNT(*) total, SUM(CASE WHEN status='in_progress' THEN 1 ELSE 0 END) for in_progress, similar for success/fail

- System stats: Query audit_logs for error_count, aggregate api_calls from audit_logs where action='query'
- Use context.Context for timeout control
- Return error if any query fails (log with zap.Error)

## Trust Boundaries

| Boundary | Description |

| API→Database | Trusted GORM queries with data scope filtering |
| API→Service | Trusted internal service calls |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | Dashboard stats endpoint | mitigate | Per D-12, enforce middleware.RequirePermission("dashboard:view") at router level to restrict access to admin role only |
| T-10-02 | Information Disclosure | Statistics aggregation | accept | Stats are non-sensitive aggregate data (counts, storage sizes). No PII or secrets exposed. |
| T-10-03 | Denial of Service | GORM aggregation queries | mitigate | Add context timeout to GetDashboardStats (ctx context.Context), use database indexes on status columns for aggregations |
| T-10-04 | Spoofing | Dashboard API requests | accept | Authentication handled by existing middleware (SM4-GCM token validation) before dashboard handler executes |
</threat_model>
