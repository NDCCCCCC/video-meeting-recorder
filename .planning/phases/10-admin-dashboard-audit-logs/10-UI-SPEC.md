## Component-Specific Contracts

### Dashboard Statistics Cards (D-01 to D-06)

**Layout:** Top section uses Ant Design Row/Col grid with responsive breakpoints (xs: 24, sm: 12, md: 8, lg: 6).

**Card structure:**
```tsx
<Card>
  <Statistic
    title={label}        // e.g., "录制任务总数"
    value={number}
    prefix={icon}        // @ant-design/icons
    suffix={unit}        // e.g., "个", "MB"
  />
</Card>
```

**Stat card categories (9 total):**
- Task stats: total, in_progress, success, fail, avg_time
- File stats: total_videos, storage_mb, transcripts, ppts
- System stats: disk_usage%, memory_usage%, error_count, api_calls

### Dashboard Charts (D-07 to D-09)

**Chart library:** @ant-design/charts v2.6.7 (Line, Column, Pie components)

**Chart configurations:**
- **Line Chart** (task trends): xField="date", yField="count", smooth=true, animation=true
- **Column Chart** (task status comparison): xField="status", yField="count", label position="top"
- **Pie Chart** (file type distribution): angleField="count", colorField="type", innerRadius=0.6 (donut)

**Chart height:** 300px (uniform across all charts for visual consistency)

**Chart tooltips:** Custom formatter showing friendly labels (e.g., "任务数: 42")

### Audit Logs Table (D-13 to D-16)

**Component:** Ant Design Table with built-in pagination

**Columns:**
1. 时间 (created_at) - 180px width, sortable, format: "YYYY-MM-DD HH:mm:ss"
2. 用户 (username) - 120px width
3. 操作 (action) - 100px width, rendered as colored Tag
4. 模块 (module) - 100px width
5. 资源 (resource) - 200px width, ellipsis if overflow
6. 状态 (status) - 100px width, Tag color based on success/error
7. 操作 (action button) - 100px width, "查看详情" link button

**Default sort:** created_at descending (newest logs first)

**Pagination:** pageSize=20, showSizeChanger=true, showTotal=(total) => `共 ${total} 条`

**Loading state:** Ant Design Table's built-in loading prop (spin overlay)

### Audit Log Filters (D-17 to D-20)

**Layout:** Horizontal toolbar with flex wrap, gap=8px between filters

**Filter components:**
- **User filter:** AutoComplete with placeholder="搜索用户名或ID", allowClear=true
- **Action filter:** Checkbox.Group with options [login, create, update, delete, export]
- **Module filter:** Checkbox.Group with options [user, role, task, file, system]
- **Time range:** RangePicker with presets [今天, 昨天, 最近7天, 最近30天]

**Filter button:** Primary button "应用过滤" + Secondary button "重置"

### Audit Log Diff Modal (D-21 to D-23)

**Component:** Modal with width=1000px, title="变更详情"

**Layout:** Side-by-side comparison using flex container
- Left panel: "变更前" (OldData) - flex=1
- Right panel: "变更后" (NewData) - flex=1
- Gap: 16px between panels

**Diff library:** diff v9.0.0 (diffJson for JSON comparison)

**Diff rendering:**
```tsx
<pre style={{ background: '#f5f5f5', padding: '12px', borderRadius: '6px' }}>
  {changes.map(part => (
    <span style={{
      backgroundColor: part.removed ? '#ffccc7' : part.added ? '#b7eb8f' : 'transparent',
      color: part.removed ? '#ff4d4f' : part.added ? '#52c41a' : 'inherit',
    }}>
      {part.value}
    </span>
  ))}
</pre>
```

**Syntax highlighting:** Basic JSON formatting (2-space indent)

### Export Button (D-24 to D-26)

**Component:** Dropdown.Button with overlay menu

**Menu items:**
- "导出为 CSV" → triggers CSV export
- "导出为 JSON" → triggers JSON export

**Button loading state:** loading={isExporting} prop

**Export limits:** Max 10,000 rows per export (backend enforced)

### Loading States (D-34 to D-36)

**Skeleton usage:**
- Dashboard stats cards: Skeleton active with 3 rows placeholder
- Audit logs table: Skeleton active with 5 rows placeholder
- Chart containers: Skeleton.Image active while data loads

**Spin usage:**
- Export button: Button loading prop (spinner inside button)
- Modal submissions: Spin component with tip="处理中..." overlay
- Async actions: Spin component with size="small"

**Reusable hook:** frontend/src/hooks/useLoadingState.ts (NEW)
```typescript
interface UseLoadingStateResult {
  loading: boolean

  execute: <T>(asyncFn: () => Promise<T>) => Promise<T | null>
```

### Error Handling (D-37 to D-39)

**Global error interceptor:** Extend existing apiClient to handle all API errors uniformly

**Error display:**
```typescript
message.error(errorMsg, 5)  // 5 seconds duration
```

**Error message format:** "{operation} 失败: {reason}"
- Example: "加载统计数据失败: 网络连接超时"
- Example: "导出日志失败: 服务器内部错误"

**API error codes mapping:**
- 401 → "登录已过期，请重新登录"
- 403 → "权限不足，无法访问此资源"
- 404 → "请求的资源不存在"
- 500 → "服务器错误，请稍后重试"

## Interactive Behavior Contracts

### Dashboard Refresh Mechanism

**Trigger:** Manual refresh button only (no auto-refresh in this phase)

**Button:** "刷新数据" with reload icon (@ant-design/icons ReloadOutlined)

**Loading state:** Button shows loading spinner during API call

**Refresh scope:** All statistics cards and charts reload simultaneously

**Cache:** TanStack Query caches stats for 60 seconds (staleTime: 60000)

### Audit Log Table Interactions

**Row click:** Opens diff modal for that log entry

**Sort click:** Toggles between ascending/descending for that column

**Pagination:** Fetches new data from backend with updated page/pageSize params

**Filter changes:** Does NOT auto-apply. User must click "应用过滤" button

**Reset button:** Clears all filters and reloads first page

### Export Flow

**CSV export:**
1. User clicks "导出为 CSV"
2. Button shows loading state
3. Backend generates CSV with current filters applied
4. Browser downloads file: `audit_logs_{timestamp}.csv`
5. Button loading state clears

**JSON export:**
1. User clicks "导出为 JSON"
2. Button shows loading state
3. Backend generates JSON array with current filters applied
4. Browser downloads file: `audit_logs_{timestamp}.json`
5. Button loading state clears

**Error handling:** If export fails, message.error() shows reason, button loading clears

## Accessibility

**Keyboard navigation:**
- Table rows: Arrow keys to navigate, Enter to open diff modal
- Filters: Tab order follows visual layout (user → action → module → time → buttons)
- Modals: Esc key closes, focus trapped inside modal

**ARIA labels:**
- Chart containers: aria-label="{chart type} showing {data description}"
- Sortable columns: aria-sort attribute (ascending/descending/none)
- Icon-only buttons: aria-label describing action

**Color contrast:** All text meets WCAG AA (4.5:1 for normal text, 3:1 for large text)
