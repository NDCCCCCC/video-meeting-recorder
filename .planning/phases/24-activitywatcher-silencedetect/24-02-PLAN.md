新建 internal/recorder/activity_watcher.go (package recorder),严格按 RESEARCH.md §ActivityWatcher 设计 + 24-VALIDATION.md §ActivityWatcher scenario matrix 实现。详细约束:

A. 类型与字段:
1. type ActivityWatcher struct 包含字段: cfg *config.Config、huaweiCli HuaweiStateClient、filePath string、logFile *os.File、logger *zap.Logger;状态字段 mu sync.Mutex、silenceSince time.Time、lastFileSize int64、lastFileGrowthAt time.Time、huaweiEmptySince time.Time、huaweiLastState string、huaweiLastJoinSum int、huaweiConsecFailures int、silenceParseFailures int、statConsecFailures int、huaweiDegraded bool、silenceDegraded bool、endedReason string;关闭字段 closeOnce sync.Once、taskEndedCh chan struct{} (buffered 1);运行时字段 now func() time.Time (默认 time.Now)、cancel context.CancelFunc、wg sync.WaitGroup。

2. type ActivitySnapshot struct { SilenceSince time.Time; LastFileGrowthAt time.Time; HuaWeiEmptySince time.Time; LastHuaWeiStateEmpty bool; HuaWeiDegraded bool; SilenceDegraded bool; Ended bool; EndedReason string; LastSilenceStart time.Time; TotalSilenceDuration time.Duration }。

3. type fakeClock struct { mu sync.Mutex; t time.Time };func (c *fakeClock) Now() time.Time { c.mu.Lock(); defer c.mu.Unlock(); return c.t };func (c *fakeClock) Advance(d time.Duration) { c.mu.Lock(); defer c.mu.Unlock(); c.t = c.t.Add(d) }。

B. 构造与生命周期:
1. func NewActivityWatcher(cfg *config.Config, huaweiCli HuaweiStateClient, filePath string, logFile *os.File, logger *zap.Logger) *ActivityWatcher:分配 watcher,初始化 taskEndedCh = make(chan struct{}, 1),now = time.Now,logger 若 nil 用 zap.NewNop()。
2. func (w *ActivityWatcher) Start():ctx, cancel := context.WithCancel(context.Background());w.cancel = cancel;wg.Add(4);go w.silenceScanner(ctx);go w.fileTicker(ctx);go w.huaweiPoller(ctx);go w.decisionTicker(ctx)。
3. func (w *ActivityWatcher) Stop():if w.cancel != nil { w.cancel() };w.wg.Wait();w.closeEnded("stopped") (仅 debug 日志)。

C. 采样 goroutine:
1. silenceScanner(ctx):bufio.NewScanner(w.logFile) 循环 Scan;每行调 p := NewSilenceParser(); ev, err := p.Parse(line);如果 err != nil → silenceParseFailures++;如果 err == nil 且 ev.Kind != None → w.mu.Lock();if ev.Kind == SilenceEventStart { w.silenceSince = w.now() };if ev.Kind == SilenceEventEnd { w.silenceSince = time.Time{} };w.mu.Unlock();silenceParseFailures 重置为 0 (成功解析 silencedetect 行)。ctx.Done() 时 return。**注意**:err == nil + ev.Kind == None (非目标行,例如 frame= ... 或 [siler 拼写错) 不算 failure,只算 Parse 静默丢弃;只统计 "[silencedetect 前缀但解析失败" 算 failure。
2. fileTicker(ctx):time.NewTicker(time.Duration(w.cfg.SmartEnd.CheckIntervalS)*time.Second);每 tick os.Stat(w.filePath);**REQUIREMENTS.md DETECT-03 rolling window + file_min_growth_bps 实现**(替换原 binary size > lastFileSize):
   - err != nil → statConsecFailures++;if >= w.cfg.SmartEnd.StatFailureThreshold → w.closeEnded("file_stat_failed");**不**清零 lastFileGrowthAt (Pitfall 6)
   - err == nil → 计算 deltaBytes := size - w.lastFileSize;if deltaBytes < 0 { deltaBytes = 0 } (文件被 truncate/替换时保守置 0)
     计算 checkInterval := int64(w.cfg.SmartEnd.CheckIntervalS);if checkInterval <= 0 { checkInterval = 1 } (避免除零)
     计算 growthBps := deltaBytes * 8 / checkInterval; (bytes/s 近似;不乘 1024 因为 cfg 单位是 B/s 而非 bps — 字段名 FileMinGrowthBPS 实际语义是 B/s,REQUIREMENTS.md 措辞"1024 B/s"对照 cfg/smart_end.go:36 注释"1024 B/s ~= 略高于比特率 8 kbps")
     if growthBps >= w.cfg.SmartEnd.FileMinGrowthBPS → w.lastFileGrowthAt = w.now();w.lastFileSize = size;重置 statConsecFailures=0
     else (增长未达阈值) → 仅更新 w.lastFileSize = size;**不**更新 lastFileGrowthAt,让 decisionTicker 自然累计 "now - lastFileGrowthAt >= file_stall_s" 触发 stall
   - **重要**:首次 stat 时 lastFileSize=0 lastFileGrowthAt=zero;如果 size==0 (录制刚开始) 不会触发 stall (lastFileGrowthAt 仍 zero 决策条件不满足);在 Start() 后第一次 fileTicker tick 时若 size > 0,deltaBytes = size(因为 lastFileSize=0),growthBps = size*8/checkInterval 远大于 FileMinGrowthBPS → 立即设 lastFileGrowthAt
3. huaweiPoller(ctx):time.NewTicker(time.Duration(w.cfg.SmartEnd.HuaweiPollIntervalS)*time.Second);**仅当 w.cfg.SmartEnd.HuaweiEnabled 为 true 时启**(Open Question 2 推荐 — huawei_enabled=false 时跳过此 goroutine,Phase 25 调度不启 watcher 时本字段也由 cfg 控制;**实现**:if !w.cfg.SmartEnd.HuaweiEnabled { return } 作为 goroutine 入口;每 tick state, err := w.huaweiCli.GetConferenceState(ctx);err != nil → huaweiConsecFailures++;if >= w.cfg.SmartEnd.HuaweiFailureThreshold → w.huaweiDegraded = true + logger.Warn("activity_watcher_degraded reason=huawei_api_unreachable");成功 → 重置计数 + 评估 confState=="" && JoinSum==0 (若 HasConferenceFields==true) 或 IsInConf==0 (fallback) → 更新 huaweiEmptySince;否则 huaweiEmptySince = time.Time{}。
4. decisionTicker(ctx):time.NewTicker(time.Duration(w.cfg.SmartEnd.CheckIntervalS)*time.Second);每 tick 评估 OR:
   - H 路径:if !w.huaweiDegraded && !w.huaweiEmptySince.IsZero() && w.now().Sub(w.huaweiEmptySince) >= time.Duration(w.cfg.SmartEnd.HuaweiPersistS)*time.Second → w.closeEnded("huawei_state_empty")
   - A+B 路径:if !w.silenceDegraded && !w.silenceSince.IsZero() && w.now().Sub(w.silenceSince) >= time.Duration(w.cfg.SmartEnd.SilenceDurationS)*time.Second && !w.lastFileGrowthAt.IsZero() && w.now().Sub(w.lastFileGrowthAt) >= time.Duration(w.cfg.SmartEnd.FileStallS)*time.Second → w.closeEnded("both_silence_and_stall")

D. 降级联动:
1. silenceScanner 累加 silenceParseFailures;每条成功解析重置;若 >= 5 (硬编码或读 cfg,推荐硬编码为常量 silenceFailureThreshold = 5 与 24-VALIDATION.md §96 "5 次连续" 对齐) → silenceDegraded = true + logger.Warn("activity_watcher_degraded reason=silence_parser_failed");若 w.cfg.SmartEnd.DegradeOnSilenceLoss == false,日志附加 "but degrade_on_silence_loss=false" 但仍不关闭路径 (Pitfall 5)。
2. silenceDegraded/huaweiDegraded 触发后**不**做自动恢复 (本阶段保持简单,Phase 25 评估)。

E. 关闭与回调:
1. func (w *ActivityWatcher) closeEnded(reason string):w.closeOnce.Do(func(){ w.endedReason = reason; close(w.taskEndedCh); logger.Info("smart_early_end (watcher)" reason=reason)});后续 closeEnded 调用 logger.Debug 不再 close。
2. func (w *ActivityWatcher) OnReconnect():w.mu.Lock();defer w.mu.Unlock();w.silenceSince = time.Time{} (仅清 silenceSince,不动 lastFileGrowthAt / huaweiEmptySince / huaweiDegraded / silenceDegraded)。

F. 公开 getter:
1. func (w *ActivityWatcher) EndedCh() <-chan struct{} { return w.taskEndedCh } // Phase 25 读
2. func (w *ActivityWatcher) IsActive() bool:锁内返回 w.endedReason == "" (close-once 后返回 false) AND (任一信号未触发 close 条件);**简化**:IsActive() 直接返回 select { case <-w.taskEndedCh: return false; default: return true } — 由 close-once 语义保证。
3. func (w *ActivityWatcher) Snapshot() ActivitySnapshot:锁内复制状态字段。
4. func (w *ActivityWatcher) ExtendStepMin() time.Duration:返回 time.Duration(w.cfg.SmartEnd.ExtendStepMin)*time.Minute。
5. func (w *ActivityWatcher) HuaweiEnabled() bool { return w.cfg.SmartEnd.HuaweiEnabled } // 暴露给 coordinator.go 用于按需注入 huaweiCli (避免在 huawei_enabled=false 时仍传 *huawei.Client 占用资源);同步满足 behavior 列表第 99 行契约。

G. 内部细节:
1. 全部状态字段读写都过 w.mu sync.Mutex;logger.Info/Warn/Debug 调用放锁外 (Copy 后再 Log)。
2. silenceDegraded/huaweiDegraded 一旦置 true 不再回退 (本阶段)。
3. now 注入字段默认 time.Now;测试可通过 w.now = fakeClock.Now 替换。
4. 不导出 taskEndedCh 字段本身,而是通过 EndedCh() 返回只读 channel。
5. 不导出 cfg/huaweiCli 等敏感字段 (保持小写)。
6. filePath 字段为 task.MKVFilePath 字符串,logFile 为 *os.File;Start 不开文件,假定调用方已创建。
