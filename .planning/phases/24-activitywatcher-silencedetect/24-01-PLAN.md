新建 internal/recorder/silence_parser.go (package recorder):
1. 定义 type SilenceEventKind int,常量 SilenceEventNone=iota、SilenceEventStart、SilenceEventEnd。
2. 定义 type SilenceEvent struct { Kind SilenceEventKind; Start, End, Duration time.Duration }。
3. 定义 type SilenceParser struct { startRe, endRe *regexp.Regexp }。
4. 实现 func NewSilenceParser() *SilenceParser:预编译两条正则:
   - startRe = `\[\s*silencedetect\s+@\s+0x[0-9a-fA-F]+\s*\]\s*silence_start\s*:\s*([0-9]+(?:\.[0-9]+)?)`
   - endRe = `\[\s*silencedetect\s+@\s+0x[0-9a-fA-F]+\s*\]\s*silence_end\s*:\s*([0-9]+(?:\.[0-9]+)?)\s*\|\s*silence_duration\s*:\s*([0-9]+(?:\.[0-9]+)?)`
5. 实现 func (p *SilenceParser) Parse(line string) (SilenceEvent, error):
   - 不含 "[silencedetect" 子串 → 返回 zero event, nil (非目标行,不算 failure)
   - startRe 命中 → SilenceEvent{Kind: Start, Start: parseFloatToDuration(matches[1])}
   - endRe 命中 → SilenceEvent{Kind: End, End: parseFloatToDuration(matches[1]), Duration: parseFloatToDuration(matches[2]), Start: End - Duration}
   - 仅含 "[silencedetect" 但两条正则都不命中 → 返回 zero event, errors.New("malformed silencedetect line: <line>") (供 watcher 累加 failures)
6. parseFloatToDuration 用 strconv.ParseFloat(s, 64) 后 * time.Second,err 同样向上抛。
7. 不做并发安全 (Parse 是无状态函数,SilenceParser 零值可用)。
