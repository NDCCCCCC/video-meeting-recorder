# Windows AD域控认证 - 管理员指南

## 概述

Record V2系统支持Windows Active Directory域控认证，允许用户使用AD账号登录系统。

## 配置步骤

### 1. 准备工作

- 有可访问的AD域控服务器
- 拥有AD域控管理员账号
- 知道AD服务器信息（地址、端口、BindDN、BaseDN）
- 前端SM4加密密钥已配置

### 2. 配置AD认证

1. 使用管理员账号登录系统
2. 导航到：系统设置 > 域控认证
3. 选择"AD域控认证"模式
4. 填写AD服务器配置：
   - **AD服务器地址**: 例如 `ad.example.com:636`
   - **BindDN**: 管理员DN，例如 `cn=admin,cn=users,dc=example,dc=com`
   - **管理员密码**: AD管理员密码
   - **BaseDN**: 域的DN，例如 `dc=example,dc=com`
   - **启用LDAPS**: 推荐勾选
5. 点击"测试连接"
6. 确认测试成功
7. 点击"保存配置"

### 3. 端口选择说明

**LDAPS端口636（推荐）**
- ✅ 加密传输，安全性高
- ✅ 适合生产环境

**LDAP端口389（仅内网测试）**
- ⚠️ 明文传输，存在安全风险
- ⚠️ 系统会显示安全警告

## 故障排查

| 问题 | 原因 | 解决 |
|------|------|------|
| 无法解析服务器地址 | DNS无法解析 | 检查服务器地址，尝试IP地址 |
| 连接被拒绝 | 防火墙阻止或LDAP服务未启动 | 检查防火墙，确认LDAP服务运行 |
| 管理员用户名或密码错误 | BindDN或密码不正确 | 检查BindDN格式和密码 |
| TLS证书错误 | LDAPS证书验证失败 | 配置正确的CA证书或使用测试模式 |
| 域控账号不存在 | AD中不存在该账号 | 确认账号在AD中存在 |
| 域控账号已禁用 | AD账号已被禁用 | 联系AD管理员启用账号 |

## 安全建议

1. **生产环境必须使用LDAPS (636端口)** - LDAP 389端口明文传输密码
2. **保护AD管理员密码** - 使用环境变量存储，定期更换
3. **最小权限原则** - 只需读取用户信息的权限
4. **审计日志** - 所有认证模式切换都会记录
