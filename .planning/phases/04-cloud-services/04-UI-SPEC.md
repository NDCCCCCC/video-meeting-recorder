## Phase-Specific Components

### 1. Transcription Dropdown Button (File List & Result Page)

**Location**: `frontend/src/pages/files/index.tsx`, `frontend/src/pages/results/index.tsx`

**Specification**:
```typescript
import { Dropdown, Button, Space } from 'antd'
import { CloudOutlined, LaptopOutlined } from '@ant-design/icons'

const items = [
  {
    key: 'local',
    icon: <LaptopOutlined />,
    label: '本地转录',
    onClick: () => handleLocalTranscribe(videoFileId, fileName),
  },
  {
    key: 'cloud',
    icon: <CloudOutlined />,
    label: '云端转录（通义听悟）',
    onClick: () => handleCloudTranscribe(videoFileId, fileName),
  },
]

<Dropdown menu={{ items }} trigger={['click']}>
  <Button type="primary" icon={<CloudOutlined />}>
    转录
  </Button>
</Dropdown>
```

**Behavior**:
- Click directly starts transcription (no extra modal step)
- Local mode: Opens TranscriptionProgressModal with sampling rate selection
- Cloud mode: Starts immediately (no parameters)
- Icons clearly distinguish modes (cloud vs laptop)

### 2. Cloud Transcription Progress Modal

**Location**: `frontend/src/components/TranscriptionProgressModal.tsx` (extend existing)

**Cloud Stages**:
```typescript
const CLOUD_STAGES = {
  uploading: { label: '上传中', icon: <CloudUploadOutlined />, percent: 0-20 },
  queued: { label: '排队中', icon: <ClockCircleOutlined />, percent: 20-30 },
  processing: { label: '处理中', icon: <LoadingOutlined spin />, percent: 30-90 },
  downloading: { label: '下载结果', icon: <CloudDownloadOutlined />, percent: 90-100 },
}
```

**Behavior**:
- Polls backend every 10 seconds (lighter than local's 5s)
- Progress bar shows percentage mapped to stage ranges
- Stage list renders with distinct cloud icons
- On fallback: Display Info alert "云端转录失败，已自动切换到本地转录", then switch to local stages

### 3. Text Content Tab (Result Page)

**Location**: `frontend/src/pages/results/index.tsx` (right panel)

**Specification**:
```typescript
<Tabs
  defaultActiveKey="info"
  items={[
    {
      key: 'info',
      label: '基本信息',
      children: <BasicInfoSection />,
    },
    {
      key: 'text',
      label: '文字内容',
      children: <TextContentTab videoFileId={videoFileId} onTimestampClick={handleJumpToVideo} />,
    },
  ]}
/>
```

**TextContentTab Component**:
- Top bar: "复制全部文字" button (right-aligned)
- Scrollable content area (max-height: 500px)
- Each segment:
  - Copy icon button (left)
  - Timestamp in monospace font, clickable (#1890FF)
  - Text content
- Timestamp format: `[HH:MM:SS]` (zero-padded)
- Copy feedback: Check icon appears for 2 seconds

**Behavior**:
- On timestamp click: Jump to video position (if player available)
- On copy segment: Copy timestamp + text to clipboard
- On copy all: Copy all segments with timestamps, newline-separated

### 4. Auto-Fallback UX

**Trigger Conditions**:
- OSS upload failure
- Tingwu API rejection (initial submission only)

**NOT Triggered**:
- Mid-processing failures (Tingwu returns error after accepting)

**Behavior**:
1. Display Info alert: "云端转录失败，已自动切换到本地转录"
2. Update TranscriptionTask.Mode from "cloud" to "local" in DB
3. Clear CloudTaskID and OSSURL fields
4. Restart progress modal with local stages
5. Frontend sync: Close and reopen modal to fetch fresh status

## Interaction Patterns

### Dropdown Button Interaction

1. User clicks "转录" button
2. Dropdown menu appears with two options
3. User selects mode:
   - **Local**: Opens modal → Select sampling rate → Click "开始转录"
   - **Cloud**: Starts immediately (no modal)
4. Progress modal shows appropriate stages based on mode

### Cloud Progress Flow

1. **Uploading (0-20%)**: OSS upload progress indicator
2. **Queued (20-30%)**: Static "排队中" stage
3. **Processing (30-90%)**: Progress bar moves, Tingwu percentage mapped
4. **Downloading (90-100%)**: Brief stage while fetching result
5. **Completed**: Navigate to result page with text content tab

### Text Content Interaction

1. User navigates to result page
2. Right panel shows tabs: "基本信息" | "文字内容"
3. Click "文字内容" tab
4. See timestamped text segments
5. Click timestamp → Video player jumps to position (if available)
6. Click copy icon → Copy segment to clipboard
7. Click "复制全部文字" → Copy all text to clipboard

## Visual States

### Cloud Transcription States

| State | Visual Indicator | User Action |
|-------|-----------------|-------------|
| Submitting | Spinner + "提交中..." | None (wait) |
| Uploading | CloudUploadOutlined + progress bar | None (wait) |
| Queued | ClockCircleOutlined + "排队中" | None (wait) |
| Processing | LoadingOutlined + percentage | None (wait) |
| Completed | CheckCircleOutlined + green | View text content, download PPT |
| Failed (initial) | Info alert + auto-switch | Wait for local to start |
| Failed (mid-processing) | CloseCircleOutlined + red | Retry with either mode |

### Text Content States

| State | Visual | Action |
|-------|--------|--------|
| Loading | Spinner | None |
| Loaded | Segments with timestamps | Click timestamp, copy |
| Empty | "暂无文字内容" | None |
| Error | "加载失败" + retry button | Click retry |

## Accessibility Notes

- Dropdown buttons: Keyboard accessible (Enter/Space to open, arrow keys to navigate)
- Timestamps: Clickable, focusable (tabindex=0), visual feedback on hover/focus
- Copy buttons: Toast notification on success
- Progress modal: Screen reader announces stage changes
- Color contrast: All text meets WCAG 2.1 AA (4.5:1 minimum)
