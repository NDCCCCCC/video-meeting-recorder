<objective>
Create backend infrastructure for slide-to-video timestamp mapping, enabling video preview synchronization with PPT slides.

This plan implements the data model, service layer, and API endpoints needed to store and retrieve slide-to-timestamp mappings. The timestamp mapper will be used by the frontend video preview component to synchronize video playback with slide navigation.

**Purpose:** Enable slide-to-video navigation by providing timestamp data for each slide.

**Output:**
- TranscriptionTask model extended with SlideTimestamps field
- TimestampMapper service for mapping retrieval and interpolation
- API endpoint GET /api/v1/transcriptions/:videoFileId/timestamps
- Database migration for timestamp tracking
</objective>

  <name>Task 2: Implement TimestampMapper service</name>
  <files>internal/services/timestamp_mapper.go</files>
  <behavior>
    - GetTimestampMap(videoFileID) retrieves slide-to-timestamp mappings from TranscriptionTask
    - Handles missing timestamps by interpolating from neighboring slides
    - Caches timestamp maps for performance (sync.Map)
    - Integrates with frame extraction data to build maps if missing
  </behavior>
  <action>
  1. Create TimestampMapper service in `internal/services/timestamp_mapper.go`:
     ```go
     type TimestampMapper struct {
         db     *gorm.DB
         logger *zap.Logger
         cache  *sync.Map // map[uint][]SlideTimestamp
     }
     ```

  2. Implement constructor:
     ```go
     func NewTimestampMapper(db *gorm.DB, logger *zap.Logger) *TimestampMapper
     ```

  3. Implement `GetTimestampMap(videoFileID uint) ([]SlideTimestamp, error)`:
     - Check cache first (cacheKey = videoFileID)
     - Query TranscriptionTask by VideoFileID
     - If not found, return error
     - Parse SlideTimestamps JSON using TranscriptionTask.GetSlideTimestamps()
     - If empty, build from frame extraction data using BuildTimestampMapFromFrames()
     - Sort by slide_number ascending
     - Cache results
     - Return sorted array

  4. Implement `GetTimestampForSlide(videoFileID uint, slideNumber int) (float64, error)`:
     - Call GetTimestampMap
     - Binary search for slide_number in sorted array
     - Return timestamp if found
     - If not found, try interpolation using interpolateTimestamp()
     - Return error if slide number is out of range

  5. Implement `BuildTimestampMapFromFrames(frames []ExtractedFrame) []SlideTimestamp`:
     - Takes array of ExtractedFrame (from FrameExtractor)
     - Builds SlideTimestamp array: slide_number = index + 1, timestamp = frame.Timestamp
     - Example: frame[0] at 0.0s → {slide_number: 1, timestamp: 0.0}
     - Return sorted by slide_number

  6. Implement `interpolateTimestamp(timestamps []SlideTimestamp, slideNumber int) float64`:
     - Find nearest slides before and after target slide
     - Linear interpolation: timestamp = (prev_ts + next_ts) / 2
     - Handle edge cases:
       - If slide_number < first slide: return first timestamp
       - If slide_number > last slide: return last timestamp
       - If only one timestamp exists: return that timestamp

  7. Implement cache management:
     - `InvalidateCache(videoFileID uint)` - clears cached map for specific video
     - Call this when new transcription completes or slides are edited

  8. Error handling:
     - Return error if videoFileID not found in database
     - Return empty array if no timestamps available (graceful degradation)
     - Log cache hits/misses for monitoring

  9. Performance optimization:
     - Use sync.Map for concurrent access
     - Sort timestamps once and cache
     - Binary search for O(log n) lookups
  </action>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-09 | Spoofing | Timestamp map access | mitigate | Validate user ownership of VideoFile via middleware.GetUserID before returning timestamps |
| T-06-10 | Information Disclosure | Timestamp data leakage | mitigate | Timestamps only returned for videos owned by authenticated user, no cross-user access |
| T-06-11 | Denial of Service | Large timestamp maps | mitigate | Limit timestamp map size to 1000 slides (reasonable PPT size), return 413 if larger, cache results with TTL |
| T-06-12 | Tampering | Client-side timestamp manipulation | mitigate | Timestamps are server-generated from TranscriptionTask, client cannot modify mapping via API |
| T-06-13 | Escalation of Privilege | Cross-user video access | mitigate | API validates VideoFile ownership before returning timestamps, checks VideoFile.CreatedBy == userID |
