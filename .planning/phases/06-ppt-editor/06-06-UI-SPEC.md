**Layout Rules:**

- Responsive: On screens < 1200px, stack video below PPT preview

## Component Specifications

### 1. Video Playback Speed Control

**Location:** Video preview panel controls (below progress bar)

**Visual:**
- Dropdown menu or segmented control
- Options: 0.5x, 1x (default), 1.25x, 1.5x, 2x
- Icon: `<DashboardOutlined />` or `<InfoCircleOutlined />` for speed indicator
- Style: Ant Design `<Select>` or `<Segmented>` component

**Interaction:**
- Click to change speed immediately
- Visual feedback: Highlight current speed
- Position: Between skip controls and fullscreen button

**State:**
- Default: 1x
- Persist per video session only (no global preference)

### 2. Side-by-Side Preview Layout

**Visual:**
- PPT preview: Left side (or top on smaller screens)
- Video preview: Right side (or bottom on smaller screens)
- Both maintain 16:9 aspect ratio
- Gap: 16px between previews

**Interaction:**
- Independent scrolling for each preview
- Bidirectional sync: PPT slide change → video seek, video timeupdate → PPT slide change
- Sync threshold: 5 seconds tolerance for automatic slide switching

**Responsive:**
- Desktop (≥1200px): Side-by-side horizontal
- Tablet (768-1199px): Stacked vertical (PPT top, video bottom)
- Mobile (<768px): Stacked, with tab switcher

### 3. Slide Capture (Direct, No Modal)

**Visual:**
- Button in operations bar: "捕获幻灯片" (primary button, icon: `<CameraOutlined />`)
- On click: Capture immediately from current video frame
- Insert position: As next slide after current slide

**Interaction:**
1. Click "捕获幻灯片" button
2. Extract current video frame
3. Insert as new slide at position (currentSlide + 1)
4. Show success message: "幻灯片已插入到位置 {newSlideNumber}"
5. Refresh thumbnails and slide count

**No confirmation modal** - direct action per requirement

**Error handling:**
- If video not loaded: Show message "视频未加载，无法捕获"
- If capture fails: Show message "捕获失败，请重试"

### 4. Thumbnail Sidebar Enhancement

**Visual:**
- Width: 160px (unchanged)
- Height: Maximizes viewport usage (remove pagination if exists)
- Scroll: Vertical smooth scrolling
- Thumbnail size: 160x90px (16:9 aspect ratio)
- Gap: 8px between thumbnails

**Interaction:**
- Click thumbnail → navigate to slide
- Active slide: Blue border (2px solid #1890ff), opacity 1.0
- Inactive slides: Transparent border, opacity 0.6
- Hover: Opacity 0.8, subtle scale effect (1.02)

**Optimization:**
- Load thumbnail images lazily (use loading="lazy")
- Show skeleton placeholders while loading

### 5. Info/Text/Operations Bar Reorganization

**Visual:**
- Position: Below preview area (moved from right sidebar)
- Layout: Horizontal tabs or sections
- No scrolling required within viewport

**Structure:**
```
┌──────────────────────────────────────────────────────────────┐
│ [基本信息] [文字内容] [操作]                                   │
├──────────────────────────────────────────────────────────────┤
│ Content area (tab-based or accordion)                         │
│ - Basic info: Video name, date, page count, file size         │
│ - Text content: Transcription text                            │
│ - Operations: Download, Retranscribe, Merge, Capture, Delete  │
└──────────────────────────────────────────────────────────────┘
```

**Interaction:**
- Tab-based navigation for info/text sections
- Operations always visible or in accessible dropdown
- Horizontal scroll if operations exceed viewport width

**Source:** Reorganization per requirement 3 (move below preview, no scrolling needed)
