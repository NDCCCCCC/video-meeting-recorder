## Background Context

**From Phase 1 (Video Splitting):**
- SplittingService.SubmitSplit creates multiple VideoFile records with `parent_id` pointing to the source video
- VideoFile model has `source_type` field to distinguish 'split' from 'recording'
- Existing GetSegmentsByParentID method retrieves all split segments for a parent

**From Phase 5 Plan 1:**
- RenameVideoFile and RenamePPTFile methods establish patterns for atomic filesystem + DB operations
- Ownership validation pattern: `file.CreatedBy == userID`

**Key Requirements:**
- D-13: Original recordings (source_type='recording', parent_id=NULL) are immutable and must NEVER be deleted
- Smart cleanup: when re-splitting video A (parent), delete all split files where `parent_id = A.id`
- Cascade deletion: delete both physical files and database records
- User confirmation: warn user before deleting existing splits

    1. **Validation Layer:**
       - Query all VideoFile records where `parent_id = parentID`
       - Filter by `CreatedBy = userID` (ownership check)
       - Filter by `SourceType IN ('split', 'snapshot')` (never delete original recordings)
       - Return early if no segments found (0, nil)
    
    2. **Cascade Deletion:**
       - Start database transaction
       - For each segment:
         - Delete physical file: `os.Remove(file.FilePath)`
         - Delete thumbnail if exists: `os.Remove(file.ThumbnailPath)`
         - Delete database record: `db.Delete(&file)`
         - Log warning if physical file deletion fails, continue with DB deletion
       - Commit transaction
       - Return count of deleted segments
    
    3. **Error Handling:**
       - On DB error: rollback transaction, return error
       - On filesystem error: log warning, continue with next file
       - Use defer func() to ensure transaction cleanup
    
    4. **Logging:**
       - Log info level: start of deletion, parentID, userID
       - Log warning level: individual file deletion failures
       - Log info level: successful completion with count
    
    5. **Implementation Pattern:**
       ```go
       func (s *VideoFileService) DeleteSplitSegmentsByParentID(parentID uint, userID uint) (int, error) {
         // 1. Query segments
         var segments []models.VideoFile
         err := s.db.Where("parent_id = ? AND created_by = ? AND source_type IN ?", parentID, userID, []string{"split", "snapshot"}).Find(&segments).Error
         if err != nil {
           return 0, fmt.Errorf("failed to query segments: %w", err)
         }
         if len(segments) == 0 {
           return 0, nil // No segments to delete
         }
         
         // 2. Delete in transaction
         err = s.db.Transaction(func(tx *gorm.DB) error {
           for _, segment := range segments {
             // Delete physical file
             if segment.FilePath != "" {
               if err := os.Remove(segment.FilePath); err != nil {
                 s.logger.Warn("Failed to delete segment file", zap.String("path", segment.FilePath), zap.Error(err))
               }
             }
             // Delete thumbnail
             if segment.ThumbnailPath != nil && *segment.ThumbnailPath != "" {
               os.Remove(*segment.ThumbnailPath)
             }
             // Delete DB record
             if err := tx.Delete(&segment).Error; err != nil {
               return err
             }
           }
           return nil
         })
         
         if err != nil {
           return 0, fmt.Errorf("failed to delete segments: %w", err)
         }
         
         s.logger.Info("Deleted split segments", zap.Uint("parent_id", parentID), zap.Int("count", len(segments)))
         return len(segments), nil
       }
       ```
