Create `internal/services/similarity_detector.go` with pure Go implementation (per D-06 — no FFmpeg filter dependency):

1. **Struct `SimilarityDetector`**:
   - Fields: `logger *zap.Logger`, `ssimThreshold float64` (0.85), `phashThreshold int` (10), `edgeThreshold float64` (0.25)
   - Constructor `NewSimilarityDetector(logger *zap.Logger) *SimilarityDetector` setting default thresholds per D-08

2. **Struct `DetectionResult`**:
   - `Changed bool` — true if any method detected change
   - `SSIMScore float64` — SSIM value (0.0-1.0)
   - `PHashDistance int` — Hamming distance
   - `EdgeChangeRate float64` — edge pixel ratio change

3. **Method `IsFrameChanged(prevImg, currImg image.Image) (*DetectionResult, error)`**:
   - Calculate all three metrics
   - OR logic per D-07: `changed = ssim < ssimThreshold || phashDist > phashThreshold || edgeRate > edgeThreshold`
   - Return DetectionResult with all values

4. **Method `calculateSSIM(img1, img2 image.Image) float64`**:
   - Convert both images to grayscale using `color.GrayModel`
   - Use 8x8 sliding window with Gaussian kernel (sigma=1.5)
   - Standard SSIM formula: (2*mu1*mu2 + C1)(2*sigma12 + C2) / ((mu1^2 + mu2^2 + C1)(sigma1^2 + sigma2^2 + C2))
   - Constants: C1 = (0.01 * 255)^2, C2 = (0.03 * 255)^2
   - Return mean SSIM value across all windows

5. **Method `calculatePHashDistance(img1, img2 image.Image) (int, error)`**:
   - Use `goimagehash.PerceptionHash(img)` for both images
   - Return `hash1.Distance(hash2)` (Hamming distance)
   - Log error and return 0 if hashing fails

6. **Method `calculateEdgeChangeRate(img1, img2 image.Image) float64`**:
   - Convert to grayscale
   - Apply Sobel operator (horizontal + vertical kernels) to get edge maps for both images
   - Sobel X kernel: [[-1,0,1],[-2,0,2],[-1,0,1]], Sobel Y kernel: [[-1,-2,-1],[0,0,0],[1,2,1]]
   - Calculate edge magnitude: sqrt(gx^2 + gy^2)
   - Threshold edge pixels: magnitude > 128 is an edge pixel
   - Count edge pixels in both images
   - Change rate = |edgePixels1 - edgePixels2| / max(edgePixels1, edgePixels2)
   - Return ratio 0.0-1.0

7. **Helper `downscaleTo720p(img image.Image) image.Image`** per D-04:
   - Target 720p = 1280x720, maintain aspect ratio
   - Use `image/draw` with `draw.CatmullRom` scaler for quality
   - Skip if already <= 720p

Create `internal/services/similarity_detector_test.go`:
