## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, button internal padding |
| md | 16px | Default element spacing, page container padding |
| lg | 24px | Section padding, card margins |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (rarely used) |

**Exceptions:**
- Modal content padding: 24px (Ant Design Modal default)
- Progress bar container: minimum 48px height for visual clarity

- Merge selection bar: 120px height (semantic exception - requires visual prominence for batch operations)

**Source:** Phase 1 UI-SPEC spacing scale (inherited for consistency), existing modal patterns in VideoPlayerModal.tsx

## Color

**Color Distribution (60/30/10 Rule):**
- **60% Dominant surfaces:** Page background (#f0f2f5) — fills majority of viewport
- **30% Secondary surfaces:** Cards, modals, content areas (#ffffff) — provides depth and hierarchy
- **10% Accent elements:** Primary actions and active states (#1890ff) — draws attention to key interactions

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #f0f2f5 | Page background, major surfaces |
| Secondary (30%) | #ffffff | Cards, modals, content areas |
| Accent (10%) | #1890ff | Primary actions, active states, progress indicators |
| Destructive | #ff4d4f | Delete actions, error states, transcription failures |
| Warning | #faad14 | Processing states, in-progress transcription |

**Accent reserved for:**
- "转录" button in file list action column
- Primary action button in transcription trigger modal ("开始转录")
- Progress bar active state (filled portion)
- Transcription completion success state (check icon, success badge)
- PPT download links in file list
- Active step in progress modal stage indicator

**Never use accent for:**
- Secondary or tertiary buttons (use default or ghost variants)
- Disabled states (use Ant Design disabled token #d9d9d9)
- Text body or labels (use #000000 or #595959)
- Border lines or dividers (use #f0f0f0)
- Failed transcription states (use destructive color #ff4d4f)
- Warning or information states (use warning color #faad14 or info color #1890ff with semantic intent)
- Background fills (use dominant or secondary surface colors)
- Non-interactive status indicators (use neutral grays)

**Warning color usage:**
- Transcription in-progress status (processing stage indicators)
- Queue status for pending transcription tasks
- Info text in transcription trigger modal

**Source:** Phase 1 UI-SPEC color system (inherited), CONTEXT.md decision D-14 (staged progress states)

## Interaction Patterns

### Transcription Trigger Flow

```
User clicks "转录" button in file list
  ↓
Open TranscriptionTriggerModal
  ↓
User selects sampling rate (default: 2秒/帧)
  ↓ [User clicks "开始转录"]
Validate selection (file exists, user has permission)
  ↓
API call: POST /api/v1/videos/{id}/transcribe
  ↓
Close trigger modal, open progress modal
  ↓
Start polling: GET /api/v1/videos/{id}/transcription-status (every 5s)
  ↓
Update progress modal with stage and percentage
  ↓ [User closes modal]
Continue background polling, show notification on completion
  ↓ [On completion]
Show success state in modal or notification
  ↓
Auto-refresh file list to show PPT download link
  ↓ [On error]
Show error state with retry option
```

**Validation:**
- File must be in "ready" status (not processing, deleting, or error)
- User must have transcription permission
- Sampling rate must be one of: 1, 2, or 5

**Error states:**
- Video file corrupted: "视频文件损坏，无法提取帧。请检查源文件或重新录制。"
- FFmpeg not found: "系统错误：FFmpeg未安装。请联系管理员。"
- Insufficient disk space: "磁盘空间不足。请清理空间后重试。"
- Frame extraction timeout: "帧提取超时。视频文件可能过长或损坏。"
- Similarity detection failed: "画面检测失败。请尝试调整采样率或联系管理员。"
- PPTX generation failed: "PPT生成失败。请重试或联系管理员。"

**Source:** CONTEXT.md decisions D-02, D-14, D-15; RESEARCH.md §Common Pitfalls

### Progress Modal Interactions

| Action | Trigger | Response |
|--------|---------|----------|
| Close modal | Click X button or "关闭" | Hide modal, transcription continues in background, polling continues |
| View progress | Modal open | Display current stage, processed/total frames, percentage |
| Download PPT | Click "下载PPT" (completion state) | Trigger browser download, close modal |
| Retry transcription | Click "重新转录" (completion/failed state) | Close modal, open trigger modal for new transcription |
| View notification | Transcription completes while modal closed | Show banner: "转录完成：{filename} - 已生成{pageCount}页PPT" |

**Polling behavior:**
- Interval: 5 seconds (CONTEXT.md D-16)
- Cancel on component unmount
- Cancel on user clicking "取消转录" (if supported)

**Source:** CONTEXT.md decisions D-15, D-16, D-17

## Accessibility Requirements

### Keyboard Navigation
- Transcription button: Tab to focus, Enter/Space to trigger
- Transcription trigger modal: Tab through radio options, Enter to confirm
- Progress modal: Escape to close, Tab to cycle through controls
- PPT download link: Standard link navigation (Enter to activate)

### Screen Reader Support
- Transcription button: "转录按钮，视频文件{filename}，时长{duration}"
- Progress modal stages: "阶段1：帧提取中，已完成。阶段2：画面检测中，已处理45帧，共200帧。"
- Completion state: "转录完成，共检测到15个画面变化，已生成PPT文件15页"
- Status badges: "转录状态：处理中"

### Icon-Only Button ARIA Labels
- Modal close button (X): `aria-label="关闭对话框"` or `aria-labelledby="modal-title"`
- Transcription action buttons (Download/Delete/Split/Transcribe): Use Button component with `icon` prop + explicit `aria-label`:
  - Download: `aria-label="下载视频文件"`
  - Delete: `aria-label="删除视频文件"`
  - Split: `aria-label="分割视频文件"`
  - Transcribe: `aria-label="开始转录"`
- Loading spinners: `aria-label="处理中"` + `role="status"`
- Status icons in progress modal: `aria-hidden="true"` (decorative, status conveyed via text)

### Visual Accessibility
- Progress bar: Minimum 48px height for visibility, high contrast colors
- Status badges: WCAG AA compliant color contrast (Ant Design default)
- Focus indicators: Visible focus ring on all interactive elements
- Loading states: Spinner icon + text label (not just color change)

**Source:** Ant Design accessibility features, Phase 1 UI-SPEC accessibility inheritance

## Performance Considerations

### Polling Optimization
- Progress polling: 5-second interval (CONTEXT.md D-16)
- File list polling: 10-second interval (existing pattern)
- Cancel polling on component unmount to prevent memory leaks
- Exponential backoff on API errors (5s → 10s → 20s → 30s max)

### Progress Modal Rendering
- Progress bar: Ant Design Progress component (optimized virtual rendering)
- Stage list: Static HTML (no re-renders unless stage changes)
- Avoid unnecessary re-renders: useMemo for stage list, useCallback for polling logic

### File List Performance
- Virtual scrolling for large file lists (if > 100 items)
- Debounce search input (300ms) to reduce API calls
- Lazy load PPT download links (only render when transcription completed)

### Memory Management
- Unload modal state on close (cleanup polling intervals)
- Cleanup event listeners on component unmount
- Avoid storing large video objects in component state

**Source:** RESEARCH.md §Pitfalls 5 (UI Responsiveness), CONTEXT.md decision D-16
