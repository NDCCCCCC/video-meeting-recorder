Create `internal/services/pptx_generator.go` using unidoc/unioffice (per D-09):

1. **Struct `PPTXGenerator`**:
   - `logger *zap.Logger`
   - Constructor `NewPPTXGenerator(logger *zap.Logger) *PPTXGenerator`

2. **Method `GeneratePPTX(ctx context.Context, framePaths []string, outputPath string) (int, error)`**:
   - Validate: len(framePaths) > 0, outputPath directory exists
   - Create presentation: `pres := presentation.New()`
   - For each framePath in framePaths:
     a. Load image: `img, err := common.ImageFromFile(framePath)` — if error, log warning and skip this frame (don't fail entire PPTX per "graceful error handling" from RESEARCH.md)
     b. Add to presentation: `imgRef, err := pres.AddImage(img)`
     c. Create slide: `slide := pres.AddSlide()`
     d. Add image to slide: `slideImg, err := slide.AddImage(imgRef)`
     e. Position and size per D-10, D-11:
        - `slideImg.Properties().SetPosition(0*measurement.Inch, 0*measurement.Inch)` — no margins
        - `slideImg.Properties().SetSize(10*measurement.Inch, 5.625*measurement.Inch)` — 16:9 full frame
   - Save: `pres.SaveToFile(outputPath)`
   - Return page count = number of slides successfully created
   - Imports needed: `"github.com/unidoc/unioffice/v2/common"`, `"github.com/unidoc/unioffice/v2/measurement"`, `"github.com/unidoc/unioffice/v2/presentation"`

3. **Method `ValidateImageFiles(framePaths []string) ([]string, []error)`**:
   - Check each file exists with `os.Stat`
   - Return valid paths and any errors
   - Useful for pre-flight validation before starting generation
