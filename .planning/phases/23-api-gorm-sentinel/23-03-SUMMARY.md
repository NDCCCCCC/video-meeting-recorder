**3. ErrInternal call-site count drift (110 → 111, +1)**
- **Source:** A CJK-comment line in `internal/services/storage/file_service.go:156` reads `// storage driver 错误 -> 包装 ErrInternal。`. Go's `regexp` `\b` treats the transition between CJK letter and Latin letter as a word boundary (Unicode-aware), whereas grep's `\b` does not. This single line is matched by the generator's regex but not by `grep -E "\bErrInternal\b"`.
- **Impact:** docs/errors.md shows 111 (generator) vs 110 (grep). This is generator-deterministic and CI-check-safe.
- **Not in scope** to change the regex semantics in this plan (per CLI: do not modify `cmd/error-doc-gen/main.go`).
