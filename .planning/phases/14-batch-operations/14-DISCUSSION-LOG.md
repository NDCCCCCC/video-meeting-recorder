## 批量下载实现

| Option | Description | Selected |
|--------|-------------|----------|
| 后端打包（Go） | 在 Go 后端使用 archive/zip 标准库创建 ZIP 文件 | ✓ |
| 前端打包（JSZip） | 在前端使用 JSZip 库打包 | |
| 后端异步打包 | 后端创建 ZIP 并保存到临时目录，完成后返回下载 URL | |

**User's choice:** 后端打包（Go）

---

| Option | Description | Selected |
|--------|-------------|----------|
| 流式响应 | 边打包边写入 HTTP 响应流 | ✓ |
| 临时文件 | 先创建完整 ZIP 文件到临时目录，然后返回文件 | |
| 异步任务 | 打包任务放入后台队列，完成后通知用户下载 | |

**User's choice:** 流式响应

---

| Option | Description | Selected |
|--------|-------------|----------|
| 保持目录结构 | 按文件原有结构组织，保持原始目录层级 | |
| 扁平带前缀 | 所有文件放在 ZIP 根目录，添加唯一前缀避免重名 | |
| 按类型分组 | 所有文件放在 ZIP 根目录，按文件类型分组到不同文件夹 | ✓ |

**User's choice:** 按类型分组

## 批量转录实现

| Option | Description | Selected |
|--------|-------------|----------|
| 独立任务 | 为每个选中的文件创建独立的转录任务 | |
| 批量任务分组 | 创建一个批量转录任务，包含多个文件 | |
| 任务组模式 | 创建一个转录任务组，包含多个子任务，支持整体取消/重试 | ✓ |

**User's choice:** 任务组模式（推荐方案）
**Notes:** 理由：统一管理、进度跟踪、可扩展性、现有兼容

---

| Option | Description | Selected |
|--------|-------------|----------|
| 顺序创建 | 顺序创建任务，每个任务完成后才开始下一个 | ✓ |
| 并发创建 | 同时创建所有任务，后台队列自动限流 | |

**User's choice:** 顺序创建

---

| Option | Description | Selected |
|--------|-------------|----------|
| 跳过继续 | 如果某个文件转录失败，继续处理剩余文件 | ✓ |
| 立即停止 | 如果某个文件转录失败，立即停止整个批量任务 | |
| 暂停询问 | 如果某个文件转录失败，暂停批量任务，询问用户 | |

**User's choice:** 跳过继续
