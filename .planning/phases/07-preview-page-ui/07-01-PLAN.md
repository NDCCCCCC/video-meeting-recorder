    ```css
    .ppt-preview-grid .thumbnail-sidebar {
      height: calc((100vw - 32px - 160px - 32px) / 2 * 9 / 16);

      overflow-y: auto;
      border-right: 1px solid #f0f0f0;
      padding: 8px;
      background: #fafafa;
    }
    ```

    The align-items: start ensures the sidebar aligns to the top of the preview area. The height calculation approximates 16:9 height based on viewport width.
