      <Tabs
        defaultActiveKey="info"
        items={[
          {

            children: (
              <Descriptions column={1} size="small">

    Replace with:
    ```typescript
    <Card size="small" style={{ marginBottom: 16 }}>
      <Space direction="vertical" style={{ width: '100%' }} size="middle">
        {/* Basic Info - no tabs */}
        <Descriptions column={2} size="small">
          <Descriptions.Item label="视频名称">{videoName}</Descriptions.Item>
          <Descriptions.Item label="转录时间">
            {currentPpt ? dayjs(currentPpt.created_at).format('YYYY-MM-DD HH:mm') : '—'}
          </Descriptions.Item>
          <Descriptions.Item label="页数">{currentPpt?.page_count || 0} 页</Descriptions.Item>
          <Descriptions.Item label="文件大小">{formatFileSize(currentPpt?.file_size || 0)}</Descriptions.Item>
          <Descriptions.Item label="类型">
            {currentPpt?.source_type === 'merge' ? '合并' : '转录'}
          </Descriptions.Item>
        </Descriptions>

        <Divider style={{ margin: '8px 0' }} />

        {/* Operation buttons - horizontal layout */}
        <Space wrap>
          <Button icon={<DownloadOutlined />} onClick={handleDownloadPpt}>
            下载PPT
          </Button>
          <Button icon={<RedoOutlined />} onClick={handleRetranscribe}>
            重新转录
          </Button>
          <Button icon={<MergeCellsOutlined />} onClick={handleMergeSlides}>
            合并幻灯片
          </Button>
          <Button icon={<DeleteOutlined />} danger onClick={handleDeletePpt}>
            删除PPT
          </Button>
        </Space>
      </Space>
    </Card>
    ```

    Key changes:
    - Remove Tabs wrapper, use Space with direction="vertical"
    - Change Descriptions column from 1 to 2 for better horizontal layout
    - Add Divider between info and operations
    - Change operation buttons Space to horizontal (remove direction="vertical")
    - Add wrap prop to allow wrapping on small screens
  </action>
