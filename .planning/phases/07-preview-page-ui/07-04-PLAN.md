# Plan 07-04: 修复缩略图高度对齐和视频黑框问题

**Objective:** 修复左侧缩略图侧边栏高度与预览区域不一致的问题，以及视频播放器下方黑框问题

**Purpose:** 确保 PPT 预览、视频预览和缩略图侧边栏三者高度完全一致，提供更好的视觉一致性

---

## Context

用户反馈的问题：
1. 左侧缩略图显示不完整 - 高度与预览区域不一致
2. 视频播放器下方有黑框 - 需要增加播放器高度与 PPT 预览对齐

当前实现：
- `.ppt-preview-grid` 使用 `align-items: start`
- `.thumbnail-sidebar` 使用计算高度 `calc((100vw - 32px - 160px - 32px) / 2 * 9 / 16)`
- 视频和 PPT 预览使用 `aspectRatio: 16/9`

  <files>frontend/src/styles/global.css</files>
  <read_first>
    - frontend/src/styles/global.css (read .ppt-preview-grid, lines 60-66)
  </read_first>
  <action>
    修改 .ppt-preview-grid 的 align-items 属性：

    当前 CSS（line 65）：
    ```css
    .ppt-preview-grid {
      display: grid;
      grid-template-columns: 160px 1fr 1fr;
      gap: 16px;
      margin-bottom: 16px;
      align-items: start;
    }
    ```

    改为：
    ```css
    .ppt-preview-grid {
      display: grid;
      grid-template-columns: 160px 1fr 1fr;
      gap: 16px;
      margin-bottom: 16px;
      align-items: stretch;
    }
    ```

    这会让所有列的高度拉伸到最高的那列（即 16:9 预览区域的高度），确保缩略图侧边栏高度与预览区域一致。
  </action>
  <verify>
