**PERF-006 (Huawei client keep-alive goroutine leak):**

1. In `internal/huawei/client.go`: add `func (c *HuaweiClient) Stop(ctx context.Context) error` method that:
   - calls `c.cancel()` to cancel the client's internal context
   - waits on a `sync.WaitGroup` for the keep-alive goroutine to exit (or use a done channel)
   - returns when goroutine confirmed stopped OR ctx timeout
2. In `internal/huawei/client.go:591-608` keep-alive goroutine: wrap the ticker loop in `<-c.ctx.Done()` exit signal. Add WaitGroup.Add(1) at start, Done() at end.

**PERF-007 (sync.Pool for high-frequency buffers — 4 处):**

3. Add `var bufPool = sync.Pool{New: func() interface{} { return new(bytes.Buffer) }}` (or `bytes.NewBuffer(nil)`) in each affected file. Wrap buffer acquisition:
   ```go
   buf := bufPool.Get().(*bytes.Buffer)
   buf.Reset()
   defer bufPool.Put(buf)
   ```
   Sites:
   - `internal/middleware/audit.go:43, 46` (request body read)
   - `internal/services/conversion_service.go:366`
   - `internal/services/snapshot_service.go:295`
   - `internal/services/frame_capture_service.go:128, 199`

**PERF-008 (正则提到包级 — 6 处):**
