# Milestone v1.0: 视频切割与会议转录PPT

**Status:** ✅ SHIPPED 2026-05-06
**Phases:** 01-14
**Total Plans:** 69

## Overview

实现视频多点分割、本地/云端转录、PPT自动生成和编辑、AD域控认证、USB和流媒体录制支持、批量操作等核心功能。

## Milestone Summary

**Decimal Phases:** 无

**Key Decisions:**
- D-01: 单一配置模型 - 保持现有配置表结构，华为终端字段改为可选
- D-02: 配置类型互斥 - 添加 config_type 字段：huawei_auto | usb | stream
- D-03: 华为开关控制 - 添加 huawei_enabled 布尔字段
- D-05: ZIP 打包位置 - 在 Go 后端使用 archive/zip 标准库
- D-11: 任务组织方式 - 使用任务组模式（TranscriptionJobGroup）
- Wave 0 测试基础设施 - 为每个阶段建立测试存根
- 多角色权限 - users_roles 多对多关系表，权限聚合使用 OR 逻辑

**Issues Resolved:**
- Token 刷新竞态条件 - 使用 Promise 缓存代替布尔标志
- 多角色迁移 GORM 约束冲突 - Migration 012 password_hash 改为 nullable
- 输入配置验证时机错误 - 修改验证逻辑位置
- 流媒体配置验证失败 - 前端字段名从 huawei_config_ids 改为 input_config_ids

**Issues Deferred:**
- Phase 01-08 UAT 测试 - UI 交互测试需要人工运行时验证
- SEED-001: TOTP 身份验证器功能 - 休眠状态，未来实现
- GPU 加速转录 - 当前使用 CPU 转录，可添加硬件加速支持

**Technical Debt Incurred:**
- 部分工作流仍有硬编码路径（Phase 05 中修复）
- 视频名称显示使用占位符而非实际文件名（Phase 03 验证中发现）
