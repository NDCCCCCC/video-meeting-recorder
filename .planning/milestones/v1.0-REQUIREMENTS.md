# Requirements: Record V2 — 视频切割与会议转录PPT

**Defined:** 2026-04-17
**Core Value:** 会议视频从录制到PPT的一站式处理，让会议内容可检索、可回顾、可分享

## v1 Requirements

Requirements for milestone v1.0. Each maps to roadmap phases.

### Video Splitting (视频分割)

- [ ] **SPLIT-01**: 用户可以在视频播放器上标记多个分割时间点
- [ ] **SPLIT-02**: 用户可以预览视频并在播放中精确定位分割点
- [ ] **SPLIT-03**: 用户确认后，FFmpeg将视频按标记点分割为多段（使用 -c copy 快速无损分割）
- [ ] **SPLIT-04**: 分割后的段落显示在列表中，可独立管理（重命名/删除/下载）
- [ ] **SPLIT-05**: 分割后的段落可以单独触发转录

### Recording Snapshot (录制快照)

- [ ] **SNAP-01**: 录制中的任务显示"生成MP4快照"按钮
- [ ] **SNAP-02**: 点击后在不中断录制的情况下导出当前已录制内容为MP4

### Auto Scan (自动扫描)

- [ ] **SCAN-01**: MP4文件生成后（录制完成/快照/分割）自动扫描并添加到文件管理页面
- [ ] **SCAN-02**: 文件管理页面实时更新，无需手动触发扫描

### Transcription (转录)

- [ ] **TRAN-01**: 用户可以手动点击"转录"按钮触发转录
- [ ] **TRAN-02**: 用户可选择"云端转录"（通义听悟）或"本地转录"
- [ ] **TRAN-03**: 云端转录失败时自动降级到本地转录
- [ ] **TRAN-04**: 转录任务状态实时跟踪（排队中/处理中/完成/失败）
- [ ] **TRAN-05**: 转录完成后用户可查看提取的文字内容（云端转录）
- [ ] **TRAN-06**: 分割后的视频段落可以单独触发转录

### Local Transcription (本地转录)

- [ ] **LCL-01**: FFmpeg按可配置采样率提取视频帧
- [ ] **LCL-02**: 三维联合变化检测去重：SSIM结构相似度（阈值<0.85判为变化） + pHash感知哈希（差异>10判为变化） + 边缘变化分析（变化率>0.25判为变化），任一维度检测到变化即保留该帧
- [ ] **LCL-03**: 去重后的帧直接生成为PPTX文件（每帧一页幻灯片）
- [ ] **LCL-04**: 本地转录进度实时反馈（已处理帧数/总帧数）

### PPT Management (PPT管理)

- [ ] **PPT-01**: 转录完成后用户可独立下载PPT文件
- [ ] **PPT-02**: PPT文件与原视频关联显示在文件列表中
- [ ] **PPT-03**: 用户可在浏览器中在线预览PPT内容（逐页浏览）
- [ ] **PPT-04**: 如果PPT缺少页数，用户可重新提交转录任务
- [ ] **PPT-05**: 同一视频保留多次转录的多个PPT结果
- [ ] **PPT-06**: 用户可从多个PPT结果中选择页面合并，生成最终PPT

### OSS Integration (OSS集成)

- [ ] **OSS-01**: 视频上传到阿里云OSS获取公网可访问URL（用于通义听悟API）
- [ ] **OSS-02**: 转录完成后自动清理OSS上的临时文件（防止持续计费）

### UI Layout (页面布局)

- [ ] **UI-01**: 视频分割页面（视频播放器 + 时间线标记 + 分割段列表）
- [ ] **UI-02**: 转录任务列表页面（转录模式/状态/进度/操作按钮）
- [ ] **UI-03**: 转录结果详情页面（文字内容 + PPT在线预览 + 下载/重试/合并操作）

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Smart Features

- **SMART-01**: 视频智能场景检测自动分割
- **SMART-02**: 静音段自动检测跳过
- **SMART-03**: 转录文字全文搜索

### Collaboration

- **COLLAB-01**: 实时协作编辑PPT
- **COLLAB-02**: 分享链接带权限控制

### Automation

- **AUTO-01**: 录制完成后自动触发转录
- **AUTO-02**: 定时自动扫描文件

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| 多语言翻译 | 通义听悟翻译功能暂不启用，仅中文转录 |
| 实时字幕 | 仅支持离线转录，不做实时语音转写 |
| PPT在线编辑 | 仅预览和下载，不提供在线编辑能力 |
| 波形显示 | 简化MVP，不在首版实现音频波形 |
| OCR文字识别 | 本地转录仅图像相似度去重，不做OCR文字提取 |
| 说话人分离 | 初期不需要区分不同发言人 |
