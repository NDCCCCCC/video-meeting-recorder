# 视频录制任务生命周期

## 一、任务生命周期概述

### 1.1 状态机图

```
                    ┌──────────────────────────────────────┐
                    │                                      │
                    v                                      │
┌──────────┐    ┌───────────┐    ┌───────────┐    ┌──────────┐
│ Pending  │───>│Connecting │───>│Recording │───>│Completed │
│  (待执行) │    │ (连接中)  │    │ (录制中)  │    │  (完成)  │
└──────────┘    └───────────┘    └─────┬─────┘    └──────────┘
     │                                  │
     │                                  │
     v                                  v
┌──────────┐    ┌───────────┐    ┌──────────┐
│Cancelled │    │  Failed   │<───│  Failed  │
│  (取消)  │    │  (失败)   │    │  (失败)  │
└──────────┘    └───────────┘    └──────────┘
                      │
                      │ (可重试)
                      v
                 ┌──────────┐
                 │ Pending  │
                 │(重新排队) │
                 └──────────┘
```

### 1.2 状态定义

| 状态 | 代码 | 说明 | 进入条件 | 退出条件 |
|------|------|------|----------|----------|
| **Pending** | `pending` | 任务已创建，等待执行 | 任务创建成功 | 到达触发时间 / 手动取消 |
| **Connecting** | `connecting` | 正在连接华为会议 | 到达触发时间 | 连接成功 / 连接失败 / 超时 |
| **Recording** | `recording` | 正在录制视频 | 连接成功 | 会议结束 / 录制失败 / 手动停止 |
| **Completed** | `completed` | 任务完成 | 录制正常结束 | - (终态) |
| **Failed** | `failed` | 任务执行失败 | 任意阶段发生错误 | - (可重试) |
| **Cancelled** | `cancelled` | 任务被取消 | 用户手动取消 | - (终态) |

### 1.3 状态转换规则

```go
// internal/models/video_recording_task.go
func (t *VideoRecordingTask) CanTransitionTo(newStatus VideoRecordingTaskStatus) bool {
    validTransitions := map[VideoRecordingTaskStatus][]VideoRecordingTaskStatus{
        VideoStatusPending: {
            VideoStatusConnecting,  // 到达触发时间
            VideoStatusCancelled,   // 用户取消
        },
        VideoStatusConnecting: {
            VideoStatusRecording,   // 连接成功
            VideoStatusFailed,      // 连接失败
            VideoStatusCancelled,   // 用户取消
        },
        VideoStatusRecording: {
            VideoStatusCompleted,   // 录制完成
            VideoStatusFailed,      // 录制失败
            VideoStatusCancelled,   // 用户停止
        },
        VideoStatusCompleted: {}, // 终态
        VideoStatusFailed: {
            VideoStatusPending,    // 重试
        },
        VideoStatusCancelled: {}, // 终态
    }

    allowed, ok := validTransitions[t.Status]
    if !ok {
        return false
    }

    for _, status := range allowed {
        if status == newStatus {
            return true
        }
    }
    return false
}
```

### 2.3 Cron 表达式生成

```go
// internal/services/video_recording/video_simple_scheduler.go
func generateCronExpression(triggerTime time.Time) string {
    // Cron 格式: 秒 分 时 日 月 周
    return fmt.Sprintf("%d %d %d %d %d *",
        triggerTime.Second(),
        triggerTime.Minute(),
        triggerTime.Hour(),
        triggerTime.Day(),
        int(triggerTime.Month()),
    )
}

// 示例:
// 触发时间: 2024-01-15 14:30:00
// Cron 表达式: 0 30 14 15 1 *
// 含义: 在1月15日 14:30:00 执行
```

## 四、任务控制操作

### 4.1 手动启动

```go
// internal/services/video_recording/video_recording_task_service.go
func (s *VideoRecordingTaskService) StartTaskManually(taskID uint, userID uint) error {
    // 1. 加载任务
    task, err := s.GetTask(taskID)
    if err != nil {
        return err
    }

    // 2. 验证权限
    if task.CreatedBy != userID && !isAdmin(userID) {
        return errors.New("无权限操作此任务")
    }

    // 3. 检查状态
    if task.Status != VideoStatusPending {
        return errors.New("只能启动待执行状态的任务")
    }

    // 4. 立即执行 (绕过调度器)
    go s.scheduler.executeTask(taskID)

    return nil
}
```

### 4.2 手动停止

```go
func (s *VideoRecordingTaskService) StopTaskManually(taskID uint, userID uint) error {
    // 1. 加载任务
    task, err := s.GetTask(taskID)
    if err != nil {
        return err
    }

    // 2. 验证权限
    if task.CreatedBy != userID && !isAdmin(userID) {
        return errors.New("无权限操作此任务")
    }

    // 3. 检查状态
    if task.Status != VideoStatusRecording {
        return errors.New("只能停止录制中的任务")
    }

    // 4. 立即完成
    go s.scheduler.completeTask(taskID)

    return nil
}
```

### 4.3 取消任务

```go
func (s *VideoRecordingTaskService) CancelTask(taskID uint, userID uint) error {
    // 1. 加载任务
    task, err := s.GetTask(taskID)
    if err != nil {
        return err
    }

    // 2. 验证权限
    if task.CreatedBy != userID && !isAdmin(userID) {
        return errors.New("无权限操作此任务")
    }

    // 3. 检查状态
    if task.Status != VideoStatusPending && task.Status != VideoStatusConnecting {
        return errors.New("只能取消待执行或连接中的任务")
    }

    // 4. 从调度器移除
    s.scheduler.RemoveTask(taskID)

    // 5. 更新状态
    task.Status = VideoStatusCancelled
    s.db.Save(task)

    // 6. 如果已连接，断开会议
    if task.Status == VideoStatusConnecting {
        s.huaweiConnector.DisconnectFromConference(task)
    }

    return nil
}
```

### 4.4 重试失败任务

```go
func (s *VideoRecordingTaskService) RetryTask(taskID uint, userID uint) error {
    // 1. 加载任务
    task, err := s.GetTask(taskID)
    if err != nil {
        return err
    }

    // 2. 验证权限
    if task.CreatedBy != userID && !isAdmin(userID) {
        return errors.New("无权限操作此任务")
    }

    // 3. 检查状态
    if task.Status != VideoStatusFailed {
        return errors.New("只能重试失败的任务")
    }

    // 4. 重置状态
    task.Status = VideoStatusPending
    task.ErrorMsg = ""
    task.RecordingFile = ""
    task.RecordingDuration = 0

    // 5. 重新计算触发时间 (当前时间 + 1分钟)
    newTriggerTime := time.Now().Add(1 * time.Minute)
    task.StartTime = newTriggerTime.Add(time.Duration(task.PreJoinMinutes) * time.Minute)

    // 6. 保存并重新调度
    s.db.Save(task)
    s.scheduler.ScheduleTask(task)

    return nil
}
```

## 六、错误处理

### 6.1 常见错误类型

| 错误类型 | 错误码 | 说明 | 处理方式 |
|---------|--------|------|----------|
| **配置错误** | `CONFIG_INVALID` | 华为配置无效 | 标记任务失败，通知用户 |
| **连接失败** | `CONFERENCE_CONNECT_FAILED` | 无法连接华为会议 | 重试3次，失败后标记任务失败 |
| **设备错误** | `DEVICE_NOT_FOUND` | USB设备未找到 | 标记任务失败，通知用户 |
| **录制错误** | `RECORDING_FAILED` | FFmpeg录制失败 | 停止录制，断开连接，标记失败 |
| **超时错误** | `OPERATION_TIMEOUT` | 操作超时 | 取消操作，标记失败 |
| **磁盘错误** | `DISK_FULL` | 磁盘空间不足 | 停止录制，清理空间，标记失败 |

### 6.2 重试策略

```go
// 连接华为会议的重试策略
func (c *HuaweiConferenceConnector) ConnectToConferenceWithRetry(task *VideoRecordingTask) error {
    maxRetries := 3
    retryDelay := 5 * time.Second

    for i := 0; i < maxRetries; i++ {
        err := c.ConnectToConference(task)
        if err == nil {
            return nil
        }

        if i < maxRetries-1 {
            time.Sleep(retryDelay)
        }
    }

    return fmt.Errorf("连接失败，已重试%d次", maxRetries)
}
```

func (s *VideoRecordingTaskService) GetTasksStatus(taskIDs []uint) map[uint]string {
    var tasks []VideoRecordingTask

### 7.2 缓存策略

```go
// 缓存华为配置 (避免频繁查询)
var huaweiConfigCache = sync.Map{} // map[uint]*HuaweiConfig

func (s *VideoRecordingTaskService) GetHuaweiConfig(configID uint) (*HuaweiConfig, error) {
    // 先从缓存获取
    if cached, ok := huaweiConfigCache.Load(configID); ok {
        return cached.(*HuaweiConfig), nil
    }

    // 从数据库加载
    var config HuaweiConfig
    err := s.db.First(&config, configID).Error
    if err != nil {
        return nil, err
    }

    // 存入缓存
    huaweiConfigCache.Store(configID, &config)

    return &config, nil
}
```
