# 前端 UI 设计规范

## 一、设计系统概述

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| **大胆表达** | 使用强烈的色彩对比和独特的视觉语言 |
| **动态感知** | 每个交互都有流畅的动画反馈 |
| **空间深度** | 通过阴影、层次和透视创造深度感 |
| **可访问性** | 保持美观的同时确保 WCAG 2.1 AA 标准 |
| **性能优先** | 60fps 的流畅动画体验 |

### 1.2 技术栈

| 技术 | 用途 |
|------|------|
| Ant Design 5.x | 基础组件库（深度定制） |
| TailwindCSS | 原子化 CSS + 自定义设计令牌 |
| CSS-in-JS (Emotion) | 动态样式与主题切换 |
| Framer Motion | 高级动画与过渡效果 |
| React Spring | 物理动画库 |

### 1.3 视觉方向定位

**风格定位：现代工业科技风**

- **色彩理念**：深邃的太空蓝背景 + 霓虹青色强调色 + 琥珀色警告点缀
- **字体理念**：技术感等宽字体 + 几何无衬线标题字体
- **形状理念**：微圆角（6px）+ 尖锐边缘 + 几何切割
- **动效理念**：弹性缓动 + 物理模拟 + 粒子效果
- **质感理念**：磨砂玻璃 + 金属光泽 + 渐变光晕

  border = true,
