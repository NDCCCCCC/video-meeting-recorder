## 🏗️ 项目架构概览

### 后端项目结构

```
record_V2/
├── cmd/
│   └── server/          # 服务入口
├── internal/
│   ├── models/          # 数据模型
│   ├── handlers/        # HTTP处理器
│   ├── services/        # 业务服务
│   ├── repositories/    # 数据访问层
│   ├── middleware/      # 中间件
│   ├── common/          # 公共组件
│   └── config/          # 配置管理
├── pkg/                 # 公共库
├── api/                 # API定义
├── configs/             # 配置文件
├── scripts/             # 脚本工具
├── docs/                # 文档
└── deployments/         # 部署配置
```

### 前端项目结构

```
web/
├── src/
│   ├── api/             # API调用层
│   ├── assets/          # 静态资源
│   ├── components/      # 组件库
│   │   ├── common/      # 通用组件
│   │   ├── business/    # 业务组件
│   │   └── layout/      # 布局组件
│   ├── hooks/           # 自定义Hooks
│   ├── layouts/         # 页面布局
│   ├── pages/           # 页面组件
│   ├── router/          # 路由配置
│   ├── stores/          # 状态管理
│   ├── styles/          # 样式文件
│   ├── types/           # 类型定义
│   ├── utils/           # 工具函数
│   ├── constants/       # 常量定义
│   └── App.tsx          # 根组件
├── public/              # 公共资源
├── index.html
├── vite.config.ts       # Vite配置
├── tsconfig.json        # TypeScript配置
└── package.json
```
