# 视觉交互设计进阶

## 一、设计理念

### 1.1 设计哲学

本系统的设计哲学是**「赛博工业科技美学」**——将工业界的技术严谨性与赛博朋克的前卫美学相融合。

**核心视觉语言：**

| 维度 | 设计语言 | 具体表现 |
|------|----------|----------|
| **色彩** | 霓虹深空 | 深邃太空蓝背景 + 电光青主色 + 琥珀橙点缀 |
| **质感** | 玻璃金属 | 磨砂玻璃 + 金属光泽 + 渐变光晕 |
| **动态** | 物理弹性 | 弹性缓动 + 流体变形 + 粒子系统 |
| **空间** | 分层景深 | 多层阴影 + 视差滚动 + Z轴分层 |
| **光影** | 自发光 | 霓虹光晕 + 内发光 + 边缘发光 |

### 1.2 设计差异点

```
传统企业应用          vs          本设计系统
────────────────────────────────────────────────
低对比度，灰白背景                  高对比度，深色霓虹
静态交互                          动态反馈
扁平设计                          玻璃态 + 深度感
通用字体                          技术感字体 (Space Grotesk)
简单阴影                          多层阴影 + 光晕
标准动画                          物理缓动 + 弹性效果
单一主题                          多层次暗色主题
```

### 5.2 粒子系统

```typescript
// src/components/Background/ParticleSystem.tsx
import { useEffect, useRef } from 'react';
import styled from '@emotion/styled';

const ParticleCanvas = styled.canvas`
  position: fixed;
  inset: 0;
  pointer-events: none;
  z-index: 1;
`;

interface Particle {
  x: number;
  y: number;
  size: number;
  speedX: number;
  speedY: number;
  opacity: number;
}

export function ParticleSystem() {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const particlesRef = useRef<Particle[]>([]);
  const animationFrameRef = useRef<number>();

  useEffect(() => {
    const canvas = canvasRef.current;
    if (!canvas) return;

    const ctx = canvas.getContext('2d');
    if (!ctx) return;

    // 设置画布尺寸
    const resize = () => {
      canvas.width = window.innerWidth;
      canvas.height = window.innerHeight;
    };
    resize();
    window.addEventListener('resize', resize);

    // 初始化粒子
    const particleCount = 50;
    const particles: Particle[] = [];

    for (let i = 0; i < particleCount; i++) {
      particles.push({
        x: Math.random() * canvas.width,
        y: Math.random() * canvas.height,
        size: Math.random() * 2 + 1,
        speedX: (Math.random() - 0.5) * 0.5,
        speedY: (Math.random() - 0.5) * 0.5,
        opacity: Math.random() * 0.5 + 0.2,
      });
    }
    particlesRef.current = particles;

    // 动画循环
    const animate = () => {
      ctx.clearRect(0, 0, canvas.width, canvas.height);

      particles.forEach(particle => {
        // 更新位置
        particle.x += particle.speedX;
        particle.y += particle.speedY;

        // 边界检测
        if (particle.x < 0) particle.x = canvas.width;
        if (particle.x > canvas.width) particle.x = 0;
        if (particle.y < 0) particle.y = canvas.height;
        if (particle.y > canvas.height) particle.y = 0;

        // 绘制粒子
        ctx.beginPath();
        ctx.arc(particle.x, particle.y, particle.size, 0, Math.PI * 2);
        ctx.fillStyle = `rgba(0, 208, 255, ${particle.opacity})`;
        ctx.fill();
      });

      // 绘制连线
      particles.forEach((p1, i) => {
        particles.slice(i + 1).forEach(p2 => {
          const dx = p1.x - p2.x;
          const dy = p1.y - p2.y;
          const distance = Math.sqrt(dx * dx + dy * dy);

          if (distance < 100) {
            ctx.beginPath();
            ctx.moveTo(p1.x, p1.y);
            ctx.lineTo(p2.x, p2.y);
            ctx.strokeStyle = `rgba(0, 208, 255, ${0.1 * (1 - distance / 100)})`;
            ctx.stroke();
          }
        });
      });

      animationFrameRef.current = requestAnimationFrame(animate);
    };

    animate();

    return () => {
      window.removeEventListener('resize', resize);
      if (animationFrameRef.current) {
        cancelAnimationFrame(animationFrameRef.current);
      }
    };
  }, []);

  return <ParticleCanvas ref={canvasRef} />;
}
```
